Monitoramento de Reservatório de Água 

Este é um projeto simples em Python desenvolvido para simular o monitoramento do nível de água de um reservatório. O sistema exibe mensagens no terminal com cores diferentes para representar o nível de risco de cada situação.

Programa desenvolvido em Python, utilizando a biblioteca colorama para mostrar as cores.
Foi utilizado também, listas e funções
